🧹 6. Toast Queue Cap & Deduplication Clean UI

During bulk AI runs across 50 videos, toasts currently stack and obscure the top-right interface.
Optimization: Cap visible toasts to max 2 concurrent banners with duplicate text suppression and 4s auto-eviction. 

// App.tsx
setToasts(prev => {
  if (prev.some(t => t.text === text)) return prev;
  const pruned = prev.length >= 2 
    ? prev.slice(prev.length - 1) 
    : prev;
  return [...pruned, { id, text, type }];
});
