Incident Root Cause & Solution

YouTube Studio API Auto-Apply Error Diagnosis

Complete technical breakdown of dual toast notifications on Youtube SEO Maximizer
Firestore Database: Saved & Verified
Score: 98/100 (0 Defects Remaining)
⚠️ Key Finding: Fixes Successfully Applied Locally, Live YouTube Push Expired
Your video optimizations were successfully generated, verified with Gemini 3.8 Flash, and stored in the database at 98/100 with all defects eliminated. However, the direct write to YouTube Studio API (videos.update) failed because the Google OAuth access token in your browser session expired after its standard 1-hour lifespan.
Anatomy of the Dual Notifications Observed in Screenshot
⚠️ Toast 1: YouTube Studio Write Warning
"YouTube Studio API note: Request had invalid authentication credentials. Expected OAuth 2 access token... Stored in database."

Root Trigger: The app called Google's endpoint https://www.googleapis.com/youtube/v3/videos?part=snippet with an OAuth token that expired. Google returned HTTP 401 Unauthorized.

✅ Toast 2: SEO/AEO Rescan Verification
"All SEO/AEO defects successfully removed! Video rescanned and verified at 98/100."

Root Trigger: As a graceful safety net, the app saved the optimized title, description, and tags directly to your Firestore database (tenants/uid/videos) and rescanned, eliminating all defects in your dashboard index.

Why the Error Repeated Across Videos State Desynchronization
Factor What Code Did Result
Token Expiry Google OAuth access tokens expire after exactly 3,600s (1 hr). Token in sessionStorage died while app was open.
Badge State Badge only checked !!getStoredYouTubeAccessToken(). Still showed ACTIVE even with dead token.
Re-Auth Hidden Button hidden when badge was "ACTIVE". You couldn't click "Authorize YouTube Write Rights".
Bulk Loop Loop didn't stop on 401; attempted every video. Fired identical warning toasts for every video processed.
Immediate 1-Click Fix (Browser Session) Immediate
1
Clear the expired session token:
Open Browser Developer Console (Cmd + Option + I or F12) and run:
sessionStorage.removeItem('yt_oauth_access_token');
window.location.reload();
2
Re-grant YouTube Studio write permissions:
Once the page reloads, click the amber button "Authorize YouTube Write Rights" in the toolbar. Complete the Google OAuth popup to get a fresh write token.
3
Auto-apply fixes live to YouTube:
Subsequent auto-apply actions will now directly update titles, descriptions, and tags live on YouTube without warning toasts.
Code Architecture Permanent Fixes Codebase Hardening
1
Auto-Expiry Invalidation (55 min TTL):
Store timestamp when token is set. Invalidate automatically after 55 minutes so the UI never displays "ACTIVE" for a expired token.
2
Instant 401 Eviction & State Reset:
When YouTube Data API returns 401, immediately clear sessionStorage and toggle hasWriteAccess to false to surface the re-authorize button immediately.
3
Always-Accessible Re-Authorization UI:
Add a "Renew Token" button directly inside the active badge so credentials can be refreshed proactively anytime without waiting for an error.
4
Bulk Loop De-duplication:
If a 401 occurs during bulk auto-apply, warn ONCE and smoothly process the rest of the batch in database-mode without flooding the screen with duplicate toasts.
